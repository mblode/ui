Blode UI is an opinionated [shadcn/ui](https://ui.shadcn.com) component registry built by [Matthew Blode](https://blode.co), with a focus on good taste, care, and craft. Open source. Open code.

## Quick Start

```bash
npx shadcn@latest init
```

Add the Blode registry and install your first component:

```bash
npx shadcn@latest registry add @blode=https://blode.co/ui/r/{name}.json
npx shadcn@latest add @blode/button
```

See the full guide at [Installation](/docs/installation).

Using Claude Code or another AI assistant? See [Skills](/docs/skills).

## Registry

The shadcn registry is hosted at [blode.co/ui](https://blode.co/ui).
