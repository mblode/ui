## Font family

Blode UI uses [Inter](https://rsms.me/inter/) as the default sans-serif font, applied with Tailwind's `font-sans` utility class, and [Geist Mono](https://vercel.com/font) as the monospace companion, applied with `font-mono`. Both are variable fonts loaded through `next/font/google`, so there are no font files to download or self-host.

```tsx
<p className="font-sans">This text uses Inter</p>
<code className="font-mono">This text uses Geist Mono</code>
```

## Configure the fonts in your root layout

In `app/layout.tsx`, import the fonts from `next/font/google`:

```tsx showLineNumbers
import { Geist_Mono, Inter } from "next/font/google";

const inter = Inter({ subsets: ["latin"], variable: "--font-inter", display: "swap" });
const geistMono = Geist_Mono({
  subsets: ["latin"],
  variable: "--font-geist-mono",
  display: "swap",
});

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en" className={`${inter.variable} ${geistMono.variable}`}>
      <body>{children}</body>
    </html>
  );
}
```

## Map the CSS variables in Tailwind

In your global CSS file, map `--font-inter` to Tailwind's `--font-sans` and `--font-geist-mono` to `--font-mono`:

```css showLineNumbers
@theme inline {
  --font-sans: var(--font-inter);
  --font-mono: var(--font-geist-mono);
}
```
