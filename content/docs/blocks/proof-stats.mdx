## Usage

```tsx
import { ProofStats, ProofStatsSkeleton } from "@/components/proof-stats";
import { getGitHubStars, getNpmDownloads } from "@/lib/live-stats";
```

```tsx
async function Stats() {
  const [stars, downloads] = await Promise.all([
    getGitHubStars("mblode/ui"),
    getNpmDownloads("blode-icons-react", "last-week"),
  ]);

  return (
    <ProofStats
      stats={[
        { label: "GitHub stars", value: stars, href: "https://github.com/mblode/ui" },
        { label: "Weekly downloads", value: downloads },
      ]}
    />
  );
}

<Suspense fallback={<ProofStatsSkeleton />}>
  <Stats />
</Suspense>;
```

## Failing closed

Proof only works when it is true. `getGitHubStars` and `getNpmDownloads` resolve to `null` on a network error, a timeout, a rate limit, or a response in an unexpected shape. `ProofStats` drops every `null` stat and renders nothing when all of them are `null`, so a failed fetch removes the number instead of showing a zero or a guess.

Both helpers cache each response for a day with `next: { revalidate: 86400 }`. Set `GITHUB_TOKEN` on the server to raise GitHub's rate limit.

Figures use the `tabular-figures` utility, so a number that changes on revalidation does not shift the stats beside it.

## Props

| Prop     | Type                                                        | Default         | Description                            |
| -------- | ----------------------------------------------------------- | --------------- | -------------------------------------- |
| `stats`  | `{ label: string; value: number \| null; href?: string }[]` | -               | The numbers. `null` values are hidden. |
| `format` | `(value: number) => string`                                 | grouped integer | Formats each value.                    |
