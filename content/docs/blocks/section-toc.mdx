## Usage

```tsx
import { SectionToc } from "@/components/section-toc";
```

```tsx
<aside className="sticky top-24 hidden xl:block">
  <SectionToc
    items={[
      { id: "how-it-works", label: "How it works" },
      { id: "faq", label: "FAQ" },
    ]}
  />
</aside>
```

Each `id` must match an element on the page. The links are plain anchors, so they work before hydration. Once the page is interactive, the section in view gets `aria-current="location"` and a heavier weight.

## Props

| Prop    | Type                              | Default          | Description                       |
| ------- | --------------------------------- | ---------------- | --------------------------------- |
| `items` | `{ id: string; label: string }[]` | -                | One entry per section (required). |
| `title` | `string`                          | `"On this page"` | Visible heading above the links.  |
