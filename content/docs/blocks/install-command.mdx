## Usage

```tsx
import { InstallCommand } from "@/components/install-command";
```

```tsx
<InstallCommand
  commands={[
    { command: "npx shadcn@latest init https://blode.co/ui/r/ui.json", label: "New project" },
    { command: "npx shadcn@latest add @blode/ui", label: "Existing project" },
  ]}
  onCopy={(label) => posthog.capture("install_command_copied", { variant: label })}
/>
```

One command renders as a single line with no tabs. Several render as tabs, and the copy button copies whichever tab is open.

When the clipboard is unavailable (an insecure context, or permission denied) the button shows an alert icon and the block tells the reader to copy the command by hand. `onCopy` only fires after a copy succeeds.

## Props

| Prop       | Type                                   | Default | Description                                           |
| ---------- | -------------------------------------- | ------- | ----------------------------------------------------- |
| `commands` | `{ label: string; command: string }[]` | -       | One entry per setup. Labels name the tabs (required). |
| `onCopy`   | `(label: string) => void`              | -       | Fires after a successful copy with the active label.  |
