## Usage

```tsx
import { Faq, faqJsonLd } from "@/components/faq";
```

```tsx
const items = [
  {
    question: "Is it free?",
    answer: "Yes. It is MIT licensed, so you can use it in personal and commercial projects.",
  },
];

<script
  type="application/ld+json"
  dangerouslySetInnerHTML={{ __html: JSON.stringify(faqJsonLd(items)) }}
/>
<Faq items={items} onOpen={(question) => posthog.capture("faq_opened", { question })} />
```

Render the JSON-LD from the same array as the list. Structured data may only claim what the page shows, and one array keeps the two from drifting apart.

Open each answer with a direct reply of 60 words or fewer. Answer engines quote the first sentences, so the answer has to stand on its own.

## Why native disclosures

Each item is a `<details>` element. Every answer is in the server HTML whether it is open or not, which is what search engines read, and items open from the keyboard before any JavaScript loads.

`faqJsonLd` returns a standalone object with `@context`. To nest it in a page's `@graph`, drop `@context` and add an `@id`.

## Props

| Prop     | Type                                     | Default | Description                                                |
| -------- | ---------------------------------------- | ------- | ---------------------------------------------------------- |
| `items`  | `{ question: string; answer: string }[]` | -       | The questions, in order (required).                        |
| `onOpen` | `(question: string) => void`             | -       | Fires when an item opens. Pass it from a client component. |
