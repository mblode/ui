## Usage

```tsx
import { CtaClose } from "@/components/cta-close";
```

```tsx
<CtaClose
  action={<Button size="lg">Open the install guide</Button>}
  command={
    <InstallCommand commands={[{ label: "npm", command: "npx shadcn@latest add @blode/button" }]} />
  }
  description="Add one component, read the file it writes, and decide from there."
  title="Add your first component"
/>
```

Repeat the hero's primary action here instead of adding a new one, so the whole page asks for one decision.

## Props

| Prop          | Type        | Default | Description                                     |
| ------------- | ----------- | ------- | ----------------------------------------------- |
| `title`       | `ReactNode` | -       | Rendered as an `h2` (required).                 |
| `action`      | `ReactNode` | -       | The page's primary action, repeated (required). |
| `description` | `ReactNode` | -       | One line under the title.                       |
| `command`     | `ReactNode` | -       | A command or snippet, such as `InstallCommand`. |
