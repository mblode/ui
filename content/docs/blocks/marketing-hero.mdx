## Usage

```tsx
import { MarketingHero } from "@/components/marketing-hero";
```

```tsx
<MarketingHero
  action={<Button size="lg">Start a free trial</Button>}
  description="For small teams who invoice by the hour: log time in one click and send the invoice from the same screen."
  eyebrow="Timesheet"
  title="Bill every hour you work"
/>
```

The title renders as the page's only `h1`, so put the words people search for in it. Keep it to three to six words a stranger understands in five seconds, and keep the subhead to one sentence: who it is for and what changes.

Nothing in the hero animates. It sits above the fold, and a hero that fades in on load delays the one thing the reader came to see.

## Props

| Prop          | Type        | Default | Description                                                          |
| ------------- | ----------- | ------- | -------------------------------------------------------------------- |
| `title`       | `ReactNode` | -       | The headline, rendered as an `h1` (required).                        |
| `description` | `ReactNode` | -       | One sentence under the headline (required).                          |
| `action`      | `ReactNode` | -       | The one primary action (required).                                   |
| `eyebrow`     | `ReactNode` | -       | Brand or product name above the headline.                            |
| `secondary`   | `ReactNode` | -       | A supporting action under the primary one, such as `InstallCommand`. |
| `children`    | `ReactNode` | -       | The signature moment: a live demo or the product itself.             |
