<Callout>

**Note:** Blode UI is a third-party shadcn registry hosted at [blode.co/ui](https://blode.co/ui). The setup flow is the same as [shadcn/ui](https://ui.shadcn.com/docs/installation) with one extra step: add the registry namespace.

</Callout>

## Fastest path

Point `init` straight at the design system. It registers the `@blode` namespace for you, sets `blode-icons-react` as the icon library, and writes Blode's tokens into your CSS in one step:

```bash
npx shadcn@latest init https://blode.co/ui/r/ui.json
npx shadcn@latest add @blode/button
```

Use the steps below instead if you already have a shadcn project.

<Steps>

### Create or initialise a project

```bash
npx shadcn@latest init
```

### Add the Blode registry

```bash
npx shadcn@latest registry add @blode=https://blode.co/ui/r/{name}.json
```

### Add the design system

```bash
npx shadcn@latest add @blode/ui
```

This writes Blode's design tokens into your CSS. Skip it and components still install, but they render unstyled: the variants compile to `rounded-[var(--field-radius)]` and `h-[var(--field-height)]`, and an undefined custom property resolves to nothing.

### Add a component

```bash
npx shadcn@latest add @blode/button
```

### Import component

The command above will add the `Button` component to your project. You can then import it like this:

```tsx {1,6} showLineNumbers
import { Button } from "@/components/ui/button";

export default function Home() {
  return <Button>Click me</Button>;
}
```

</Steps>
