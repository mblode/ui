## Usage

```tsx
import {
  Step,
  StepContent,
  StepDescription,
  StepIndicator,
  StepLabel,
  StepSeparator,
  Stepper,
} from "@/components/ui/stepper";
```

```tsx
<Stepper aria-label="Checkout" value={1}>
  {steps.map((label) => (
    <Step key={label}>
      <StepIndicator />
      <StepLabel>{label}</StepLabel>
      <StepSeparator />
    </Step>
  ))}
</Stepper>
```

`value` is the zero-based index of the active step. Every earlier step is `completed`,
every later one `pending`. That is the same `data-state` vocabulary
[progress-list](/docs/components/progress-list) uses, so one selector styles both.

Stepper is a wayfinding control for a flow the user is moving through. For a read-only
display of work already under way, reach for
[progress-list](/docs/components/progress-list) or
[thinking-steps](/docs/components/thinking-steps).

The stepper renders an `<ol>` and each step an `<li>`: the flow is announced as an ordered
list. The active step carries `aria-current="step"`, and each step opens with visually hidden
text, “Step 2 of 4, current step”, so position and state never rest on colour alone.
`<StepSeparator>` renders nothing after the last step. Place it inside every step without a
special case.

Numbers in the indicator use the `tabular-figures` utility. The circles hold their width from
step 9 to step 10.
