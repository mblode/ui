## Usage

```tsx
import { Share } from "@/components/ui/share";
```

```tsx
<Share text="Our Q3 roadmap, now with dates." title="Q3 roadmap" value="https://blode.co/ui" />
```

`Share` calls `navigator.share` where the browser has it: a phone, or Safari and Edge on
the desktop. Everywhere else it copies `value` to the clipboard and raises a toast, so the
button always does something. Add a `<Toaster />` to your layout for the fallback to be
visible.

Dismissing the share sheet is not a failure. `AbortError` and `NotAllowedError` reset the
button silently: no confirmation tick, no error toast. Any other failure falls through to
the copy path.

The tick appears only once the share resolves, so it means the sheet actually completed.

## With a label

Set `showLabel` to render `label` as visible text beside the icon. The accessible name
then comes from the text itself, not from `aria-label`.
